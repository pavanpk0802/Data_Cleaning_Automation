## Project Overview

Data Cleaning Automation is a Python-based project that automates common data cleaning tasks such as handling missing values, removing duplicates, cleaning text fields, and validating data quality.

## Objectives

- Identify missing values.
- Remove duplicate records.
- Clean inconsistent text data.
- Handle missing numerical values.
- Validate the cleaned dataset.
- Compare data quality before and after cleaning.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Data Cleaning Process

1. Inspect the raw dataset.
2. Identify missing values.
3. Remove extra spaces.
4. Fill missing values.
5. Remove duplicate records.
6. Reset the dataset index.
7. Validate the cleaned dataset.
8. Compare data quality before and after cleaning.

## Results

The automated process successfully cleans the dataset and provides a comparison of data quality before and after cleaning.
